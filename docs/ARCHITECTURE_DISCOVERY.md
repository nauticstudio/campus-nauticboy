# Architecture Discovery

## Repository Summary
The repository `nautic-campus` is a modern web application designed for a private music production academy (Nautic Campus). It serves as an LMS (Learning Management System) and a software distribution platform. The platform supports two main roles: Administrators and Students (Alumnos), with distinct dashboards and access privileges. It is built using a modern JavaScript/TypeScript ecosystem with server-side rendering and a managed PostgreSQL database.

*Evidence: `package.json`, `src/app/(campus)/dashboard/page.tsx`, `src/components/layout/ViewModeSwitcher.tsx`*

## Architecture Summary

The project follows a modular, feature-based architecture within the Next.js App Router paradigm:

1. **Routing & Application Layer (`src/app/`)**
   - Route Groups: `(auth)` for authentication flows, `(campus)` for the main authenticated application.
   - API Routes & Server Actions: `api/` and `actions/` (e.g., `view-mode.ts`, `software.ts`) for server-side logic and database mutations.

2. **Component Layer (`src/components/`)**
   - Contains reusable UI components and layout structures.
   - `layout/`: Global navigation components (`Sidebar.tsx`, `Header.tsx`, `CommandMenu.tsx`, `ViewModeSwitcher.tsx`).
   - `ui/`: Likely contains primitive UI components generated by Shadcn UI.

3. **Core Services & Infrastructure (`src/lib/`)**
   - `supabase/`: Contains Supabase client instantiation for both client-side and server-side contexts.
   - `google-drive/`: Contains authentication (`auth.ts`) and file management logic (`files.ts`) for integrating with Google Drive.
   - `data/`: Contains data access objects or repository-like functions.

4. **Database Schema & Migrations (`supabase/`)**
   - Contains raw SQL scripts for schema definition and database seeding (`software_schema.sql`, `software_full_seed.sql`, `seed.sql`).
