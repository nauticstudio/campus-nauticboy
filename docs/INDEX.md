# Documentation Index

## Overview
This is the root of the documentation hierarchy for the Nautic Campus project. The documentation is the Primary Source of Truth. The repository is documentation-driven, and implementation exists to satisfy documentation.

## Documentation Hierarchy
The documentation is organized by authority levels. Higher authority documents define lower authority documents.

1. **L0 - Governance** (Highest Authority)
   - [Agents Governance](L0-Governance/AGENTS.md) - Behavioral rules and AI-Native mode.
   - [Operating Rules](L0-Governance/RULES.md) - Coding standards and architectural baseline.
   - [Manifest](MANIFEST.yaml) - Registry of all project documentation.

2. **L1 - Strategy**
   - [Strategy](L1-Strategy/STRATEGY.md) - Product vision and business logic constraints.

3. **L2 - Architecture**
   - [Architecture Discovery](ARCHITECTURE_DISCOVERY.md) - Baseline snapshot of the current architecture based on repository evidence.

4. **L3 - Implementation**
   - [Implementation Specs](L3-Implementation/IMPLEMENTATION.md) - Next.js routing, component structure, and Supabase interaction rules.

5. **L4 - Operations**
   - [Operations](L4-Operations/OPERATIONS.md) - Build commands, environment variables, and migration strategies.

6. **L5 - Knowledge**
   - [Knowledge Graph](KNOWLEDGE_GRAPH.md) - Mapping of core domains, entities, and technical relationships.
