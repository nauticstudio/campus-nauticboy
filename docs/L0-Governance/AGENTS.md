# Agents Governance (L0-Governance)

## Overview
This document defines the behavioral rules, constraints, and operational modes for all AI Agents interacting with the Nautic Campus repository. It establishes the baseline for AI-assisted autonomous development.

## 1. Operating Modes
- **AI-Native Operating Mode**: The repository is documentation-driven. Documentation is the Primary Source of Truth. Agents MUST NEVER bypass the documentation hierarchy.
- **Incremental Documentation Mode**: Agents MUST update only one documentation file per execution unless explicitly authorized by a human lead.

## 2. Startup Sequence
At the beginning of every new conversation or task, AI Agents MUST read the following foundational documents in order:
1. `docs/INDEX.md`
2. `docs/MANIFEST.yaml`
3. `docs/KNOWLEDGE_GRAPH.md`
4. `docs/L0-Governance/AGENTS.md`
5. `docs/L0-Governance/RULES.md`

## 3. Technology-Specific Agent Rules
